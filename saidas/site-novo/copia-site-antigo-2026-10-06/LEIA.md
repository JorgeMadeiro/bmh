# Cópia do site antigo (06/10/2026)

Feita antes de qualquer mudança no site, pela API (só leitura) e pelo navegador, com os rastreadores bloqueados
(não gerou visita no Analytics nem conversão).

- `paginas.json`: as 11 páginas (10 publicadas e a "Política de privacidade" em rascunho, id 3).
- `api/`: os dados de cada página como o WordPress guarda, mais `ajustes.json`, `plugins.json` (9 ativos) e
  `biblioteca-midia.json` (103 arquivos).
- `html/`: o HTML de cada página publicada, como o visitante recebe.
- `telas/`: foto da página inteira no computador (1366 px) e no celular (390 px).

O conteúdo visual do Elementor (`_elementor_data`) não sai pela API: para restaurar uma página do Elementor, o
caminho é o backup da Hostinger. Esta cópia serve para comparar antes e depois e para não perder texto nenhum.
